User & Account Management

Account credentials and permissions are managed by Supabase Authentication.

Secure account setup: Create or disable users in Supabase Authentication, then assign each user's admin or staff role in the protected kbk_profiles table. Passwords are never stored by this browser app.

Account administration

Use the Supabase project dashboard to manage sign-in methods, reset passwords, deactivate accounts, and grant roles.

Move saved browser records to the shared database

The first administrator sign-in preserves this browser's old records as a local backup. Import only after reviewing them; this replaces the corresponding shared record lists.
